# 僵尸亮了 · 让子弹射 · 自动玩

打开就自动玩，全程零人工：自动进关 → 自动作战 → 死了自动重开，无限连播。

## 这个仓库里有什么

本仓库只放我们自己的代码：

- `index.html` —— 页面外壳（加载游戏 + 装载自动玩脚本）
- `autoplay.js` —— 自动玩逻辑（进关导航、策略闭环、结算重开）

游戏本体的脚本与素材**一个字节都没有改**，全部从游戏自己的官方 CDN 现拉
（游戏配置里 `assets.server` 本来就是这个地址）；本仓库不含任何游戏素材。

## 说明

- 第一次打开需要下载游戏资源，稍等片刻。
- 链路：官方游戏页面 → 本页壳接管 → 自动进入「让子弹射」第 1 关 → 内置策略循环作战。
- 底部有操作记录可查：打开控制台可见 `[ap]` 日志（进关 / 注入 / 每局结算 / 重开）。
